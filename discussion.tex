\section{Discussion}
In this work we presented pod, a novel consensus layer which finalizes transactions with optimal one round-trip latency. Pod eliminates communication among replicas. Instead, clients read the state of the system by performing lightweight computations on the logs that replicas send to them. We also saw how pod can be used as a bulletin board for efficient and censorship-resistanct auctions.
